# NumPy Practice & Data Analysis Exercises

This repository contains several practice problems and data manipulation tasks solved using the NumPy library. It includes tasks such as student data analysis and Valid Sudoku validation.

## 🚀 Features & Operations Covered
- **Valid Sudoku Matrix:** Creating and validating a Sudoku matrix using NumPy arrays.
- **Student Data Analysis:** 
  - Finding the matrix shape.
  - Calculating the average age of students.
  - Extracting Math and Science subject marks and finding the maximum marks.
  - Filtering students based on conditions .
  - Updating or replacing marks .
  - Calculating column-wise mean or average marks.

## 🛠️ Technologies Used
- Python
- NumPy
- Jupyter Notebook / VS Code
